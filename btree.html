Python Algorithms Data Structures Disk-Based Storage Disk I/O Optimization Database Indexing
📘
Project Overview

This project implements a disk-based B-Tree data structure that simulates how databases manage indexing when nodes must be persisted to disk instead of memory. The tree supports efficient insert and find operations while maintaining balance.

⚙️
Core Operations
  • insert(key, value) — Insert or overwrite keys while maintaining invariants
  • find(key) — Return the value for a key or None
🌲
Structural Constraints
  • Keys remain sorted
  • Height stays balanced
  • Branching factors: M (internal nodes), L (leaf nodes)
💾
Disk-Based Architecture
  • Each node resides in a disk block
  • Only m, l, and the root address stay in memory
  • All interactions go through DISK.new(), DISK.write(), DISK.read()
🧠
Implementation & Problem-Solving Highlights
  • Managing a fully disk-backed data structure requires careful logic.
  • Splits and redistribution required precise debugging.
  • Visualization and tests revealed subtle structural bugs.
  • Ensuring correctness required extensive Pytest coverage.
