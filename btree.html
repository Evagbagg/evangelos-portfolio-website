B-Tree Data Structure

Python Algorithms Data Structures Disk-Based Storage Disk I/O Optimization Database Indexing

This project explores the internals of a fully implemented B-Tree — a disk-based, high-performance indexing structure used in databases, filesystems, and large-scale storage systems. The implementation supports core dictionary operations, efficient node splitting, persistence through disk blocks, and optimized search through binary lookup across m-ary nodes.
