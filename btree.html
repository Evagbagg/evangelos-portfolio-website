B-Tree Data Structure

Python Algorithms Data Structures Disk-Based Storage Disk I/O Optimization Database Indexing

This project explores the construction of a fully functional disk-based B-Tree — an essential indexing structure used in large-scale databases and file systems. The implementation supports insertion and search operations, maintains strict balancing, and stores all nodes on disk rather than memory, simulating real database engine constraints.
