B-Tree Data Structure

Python Algorithms Data Structures Disk I/O Simulation

This project explores the implementation of a B-Tree, a balanced search tree widely used in databases and file systems. The focus of the project was to correctly implement node splitting, key insertion logic, and disk-based storage operations.

The final implementation supports customizable order, persistent storage simulation, and includes visualization outputs to help understand how the tree evolves during insertions.
